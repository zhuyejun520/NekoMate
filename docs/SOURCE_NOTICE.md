# NekoMate 源码导出

本导出中的服务器地址已全部替换为 `YOUR_SERVER` / `YOUR_SERVER:8080`。

使用前请替换：

- `android/src/com/nekocyte/companion/Session.java` 的默认服务器地址
- `android/res/layout/activity_login.xml` 的登录页提示
- `server/app/config.py` 的 `public_base_url`
- `server/docker-compose.yml` / `server/.env.example` 的 `NM_PUBLIC_BASE_URL`

也可以直接在客户端登录页填写自己的服务器地址。
