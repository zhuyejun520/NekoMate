## 2.3.8 语音转文本修复

- 根因：默认选中的 DeepSeek chat 提供商没有 `/audio/transcriptions`，返回 HTTP 404。
- 服务端新增 STT 提供商选择，优先选择 `open.bigmodel.cn` 的 GLM 提供商。
- GLM-ASR 使用模型 `glm-asr-2512`，接口：

```text
POST https://open.bigmodel.cn/api/paas/v4/audio/transcriptions
```

- 录音从 AAC/m4a 改为 16kHz 单声道 PCM WAV，兼容 GLM-ASR 仅支持 wav/mp3 的限制。
- 录音最长 30 秒。
- 服务端上传白名单新增 `.wav`。
- AI 回复前的语音转写也走同一套 STT 提供商选择。
- 服务端 1.9.6。

## 2.3.7 语音消息

- 对面或自己点击语音气泡播放服务端音频。
- 新增 `AudioCache`：语音文件离线缓存、消息加载时预取。
- 长按自己的语音消息可撤回；服务端撤回时删除源文件。
- 长按任意语音可选择「转文本」；服务端 1.9.5 新增 OpenAI 兼容 `/audio/transcriptions` 转写。

## 2.3.4 Root 通知增强（可选）

- 设置 → 通用新增「Root 通知增强（实验）」，默认关闭。
- 开启后先执行 `su -c id` 检查 root；没有 root 自动关闭开关并回退普通通知。
- AI 好友消息优先通过 root 启动前台服务，由应用自己的通知通道发布可点击通知：

```text
su -c am start-foreground-service \
  -a com.nekocyte.companion.ROOT_NOTIFY \
  -n com.nekocyte.companion/.UsageMonitorService \
  --es token <token> \
  --es title_b64 <Base64标题> \
  --es text_b64 <Base64正文> \
  --ei conv_id <会话ID>
```

- 标题/正文使用 Base64 传递，避免 shell 空格和引号导致消息被截断。
- 这是 ColorOS/OnePlus 上验证过的方式；直接 `cmd notification post` 会落到系统 shell 通道，部分 ROM 不展示。
- root 命令失败自动回退普通 NotificationManager。
- 开启时会尝试执行：
  - `dumpsys deviceidle whitelist +com.nekocyte.companion`
  - `cmd appops set com.nekocyte.companion RUN_IN_BACKGROUND allow`
- 普通好友/群聊通知仍走原逻辑；root 增强只作用于 AI 好友通知。
- 服务端不需要更新，继续使用 1.9.4。

## 3. 权限与 root

### 3.1 通知权限

Android 13+ 首次进入主界面会弹通知授权，选「允许」，否则 AI 主动消息不会弹通知。

### 3.2 使用情况访问（非 root 也能用）

AI 设置 →「打开『使用情况访问』设置」→ 找到「夜音」→ 允许。
这是系统特殊权限，用于检测当前前台应用。

### 3.3 root（可选）

支持 Magisk / KernelSU 等 `su` 环境：

1. 手机已 root，且授权管理器允许「夜音」使用 root。
2. AI 设置 → 打开「root 权限」开关。
3. 点「用 root 自动授权」，会执行：
   ```
   su -c appops set com.nekocyte.companion GET_USAGE_STATS allow
   ```
4. 打开「后台陪伴」开关，授予通知权限。

没有 root 也可以用：只要授予「使用情况访问」权限，同样能检测前台应用；root 只是让授权和部分 ROM 上的检测更可靠。

### 3.4 后台保活

- 开启「后台陪伴」后，会有一个常驻通知「夜音正在陪伴」。
- 部分国产 ROM 会杀后台，建议在系统设置里允许「夜音」自启动、后台运行、关闭电池优化。
- 服务每 2 秒检测一次前台应用，每 30 秒拉一次会话用于主动消息通知。

## 4. 白名单应用

AI 设置 →「白名单应用」：

- 「＋ 添加白名单应用」→「从已安装应用选择」，直接点应用即可自动填包名和名称；
- 也可以手动输入包名，例如 `com.sankuai.meituan`，备注「外卖」。

打开白名单里的应用时：

1. 客户端检测到前台包名；
2. 上报到服务端 `/api/v1/ai/friends/{id}/usage-events`；
3. 服务端结合时间、天气、备注生成一句自然的话；
4. 写入 AI 会话并推送给客户端；
5. 客户端通知栏弹出 AI 消息（如果 App 不在当前聊天页）。

默认服务端有 15 分钟冷却，避免连续轰炸；内置外卖、淘宝、微信、抖音、B 站等 18 个常见应用白名单。

### 4.1 群成员：创建后继续拉人、邀请 AI

群聊页 → 进入群 → 右上角「⚙」：

- 「＋ 邀请好友进群」：列出还未入群的好友，多选后邀请；
- 「＋ 邀请 AI 好友进群」：把自己名下的 AI 好友拉进群；
- 群成员列表会同时显示真人和 AI，AI 带「AI 好友」标记；
- 群主或 AI 主人可以点 AI 后面的「移除」；
- 群里有人发言时，被拉进来的 AI 会结合群成员、最近聊天记录和最后一条消息自动接话，不会代替其他人说话。
- 如果 AI 所属用户配置了专属 Key，群内回复也会走那把专属 Key。

### 4.2 日常编辑器

日常页 →「＋ 发布日常」打开全屏编辑器：

- 大输入框、2000 字计数；
- 两个图片入口：「＋ 从相册添加」和「＋ 从文件管理选择」；
- 相册优先使用系统 Photo Picker；文件管理使用 `ACTION_OPEN_DOCUMENT`，只显示本地文件，OPPO 等机型建议用这个入口；
- 选中后立即读取并复制到 App 缓存，授权只在复制成功后尝试持久化；
- 如果图片已被删除、文件管理未授权或还在云端未下载，会提示重新选择；
- 缩略图预览，长按移除；
- 发布时先上传图片，再带上图片 URL 发布动态；
- 动态列表直接显示图片缩略图（最多 3 张 + 剩余数量）。

## 5. 主题、聊天背景与私人角色卡

### 5.1 浅色 / 深色主题

「我的」→「切换主题」：

- 浅色（默认）：白底卡片 + 深色文字；
- 深色：暗色极光风格。

选择后立即保存并重建界面，登录页、好友、AI、群聊、日常、聊天、AI 设置全部跟着切换。首次安装默认浅色，不跟随系统。

### 5.2 自定义聊天背景

「我的」→「选择聊天背景」→ 选择「从相册选择」或「从文件管理选择」。

- 图片会复制到 App 私有目录 `files/chat_bg.png`，只在本机生效；
- 聊天页会自动加一层半透明遮罩，保证气泡文字可读；
- 「恢复默认聊天背景」可以清除。

### 5.3 后台消息通知

登录后客户端会启动前台消息服务，约每 10 秒同步一次会话：

- 好友私聊、群聊、AI 好友的新消息都会进通知栏；
- 群聊通知标题是群名，正文带发送者，例如「好友一：晚上一起吃饭吗」；
- AI 主动消息、root 使用事件触发的 AI 回复也会通知；
- 点通知直接打开对应会话；
- 正在看的那个会话不会重复弹通知，切到后台后恢复通知；
- 「后台陪伴」开关只控制白名单应用检测，关闭后聊天通知仍然保留；
- 通知栏常驻通知里的「停止」会停止整个后台消息服务，重新打开 App 会再启动。

### 5.4 专属模型 Key 与私人角色卡

管理员在 Web 控制台 →「用户」→「专属Key」给某个用户分配至少一个专属模型 Key 后：

- 该用户的 AI 对话、主动消息、记忆分析只走这把 Key，不会消耗全局 Key 的 token；
- 安卓端「AI 好友」页会出现「＋ 创建私人角色卡」；
- 创建的私人角色卡只有自己能看到，多个专属 Key 用户之间不互通；
- 可以编辑、删除，并像公开角色卡一样添加为 AI 好友。
- 私人角色卡右侧「知识库」：新建私人知识库、导入 TXT、导入聊天记录长截图（视觉 OCR）、按角色启用/停用。

没有专属 Key 的账号看不到这个入口，也不能通过接口创建私人角色卡。

## 6. 客户端更新

客户端启动时会请求服务端 `/api/v1/app/version`：

- 如果服务端发布了更高的 `versionCode`，弹窗显示版本号、更新日志、安装包大小；
- 点「下载更新」会走系统 DownloadManager 从服务端拉取 APK，下载完成后自动打开安装界面；
- 非强制更新可以点「稍后」，同一版本不再重复提示；
- 强制更新弹窗不可取消，只能更新或退出；
- 首次安装需要在系统里允许「夜音」安装未知应用。

管理员在 Web 控制台 →「客户端更新」上传 APK，填写 versionCode、versionName、更新日志和是否强制。

## 7. 记忆与主动消息

- **记忆**：每条消息由服务端分析模型判断重要性；重要内容长期保存，普通内容只保留 2 天。AI 设置 →「记忆」可以查看和删除。
- **主动消息**：
  - 超过 30 分钟没聊天 → 本次会话结束；
  - 随机 1–3 小时后 AI 主动发一条（聊之前的话题 / 天气 / 闲聊）；
  - 连续主动 3 次没回复 → 停止，等你先开口；
  - 你回复后重新开始循环。
- AI 设置里可以调整空闲分钟、最小/最大间隔、最多连续次数，也可以点「立即让她主动说一句」测试。

## 9. 网络说明（重要）

服务端目前在纯 IPv6 地址上，域名 `127.0.0.1` 只有 AAAA 记录：

- 手机使用移动数据（移动/联通/电信 5G 通常有 IPv6）可以正常访问；
- 部分只分配 IPv4 的 Wi-Fi 会连不上，表现为登录超时；
- 如果需要 IPv4 兼容，需要在服务端前加一台有 IPv4 的机器做反代/FRP，或使用 Cloudflare Tunnel/ZeroTier。

客户端本身已开启明文 HTTP（`usesCleartextTraffic` + `network_security_config`），不需要 HTTPS 证书。

## 12. 已知限制（v1.2）

- 聊天支持文字和图片；语音、文件暂未接入。
- 聊天图片需要服务端配置「视觉模型」；没有视觉模型时图片仍能发送，AI 会说明识别不可用。
- Markdown 通过「导入 Markdown 文件」进入渲染模式；普通文本仍按纯文本显示。
- 视频只识别标准视频链接；`b23.tv`、`v.douyin.com` 等短链需要先展开成标准链接。
- 抖音分享页在 WebView 内的播放能力受抖音页面策略影响；默认会尝试暂停，必要时点页面内的播放按钮。
- 表情包搜索依赖 `api.ruseo.cn`，离线时只能使用已收藏的常用表情。
- 表情包 API 返回的 GIF 在 Android 9+ 会播放动画，旧系统只显示首帧。
- 聊天背景只保存在本机，不随账号同步到其他设备。
- 实时消息使用轮询（聊天页 3 秒、后台通知约 10 秒），没有直接使用服务端 WebSocket。
- 后台服务会被部分 ROM 杀死；需要手动加白名单/关闭电池优化。
- 服务端是纯 IPv6，IPv4-only Wi-Fi 无法连接（见第 9 节）。
- 客户端更新需要允许「安装未知应用」；部分 ROM 会二次确认。
- 未做多语言，界面为简体中文。
